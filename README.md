# Site — Entrepreneur en événementiel sportif

Site HTML/CSS prêt pour GitHub Pages.

## Mise en ligne sur GitHub
1. Créer un nouveau dépôt GitHub.
2. Décompresser ce dossier et déposer **tous les fichiers** à la racine du dépôt.
3. Aller dans `Settings` → `Pages`.
4. Choisir `Deploy from a branch`, puis la branche `main` et le dossier `/ (root)`.
5. Enregistrer : GitHub Pages publiera le site.

## Contenu
- `index.html` : page principale
- `style.css` : charte et responsive design
- `assets/` : rapports PDF, guide PDF, image de synthèse et podcast
- Les sources sont cliquables directement dans la section « Ressources ».

## Identité visuelle
Le design reprend l'association violet + turquoise présentée comme identité d'IMT-BS dans les ressources officielles. Le logo institutionnel n'est pas reproduit graphiquement dans le code : le bandeau utilise une marque textuelle pour rester facilement modifiable.

## Important
Les informations métier et les chiffres affichés sur le site sont issus des documents de recherche fournis pour le projet. Pour une utilisation professionnelle réelle, les informations réglementaires doivent être vérifiées auprès des autorités compétentes.
